# End of life — USB-C rear shells

These shells are **not** the current release. They are kept here for existing prints and archives.

The rear USB-C cutout is not compatible with the USB-C specification (connector, clearance, and cable/plug geometry). Do not use these for a new build. Print a **`v1`** shell instead — those have Ethernet, a DC jack, and a power button.

stls/shell/eol/usbc-ethernet/
