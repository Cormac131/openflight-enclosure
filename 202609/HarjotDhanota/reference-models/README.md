# Reusable reference models

These STEP files are separated from the printable enclosure so they can be reused when designing alternative OpenFlight enclosures.

They represent non-printing electronics, sensors, radars, connectors, and assembly hardware. Some models are simplified clearance envelopes while others retain more detailed vendor geometry. Do not treat cosmetic detail as a substitute for checking the physical component or its latest mechanical drawing.

The Ethernet panel-coupler model is retained here even though it is intentionally hidden in the submitted complete assembly.
